# Nova Studio Landing Page

A modern and responsive Design Agency Landing Page built with React, Tailwind CSS, and Framer Motion.

## Preview

Nova Studio is a premium landing page designed for creative agencies, design studios, startups, and freelancers. It features modern UI patterns, smooth animations, responsive layouts, and dark mode support.

---

## Features

* Modern Agency Landing Page
* Fully Responsive Design
* Dark / Light Mode
* Framer Motion Animations
* Reusable Components
* Mobile Navigation
* FAQ Accordion
* Pricing Section
* Portfolio Showcase
* Testimonials Section

* Contact Form
* Clean Project Structure

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/nova-studio.git
```

Navigate to the project folder:

```bash
cd nova-studio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
